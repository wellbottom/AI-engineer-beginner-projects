# Streaming: POST /ask streams over SSE using FastAPI's StreamingResponse with the
# shared ai_shared.sse frame helpers (so the wire format is identical to every
# other service and to what the frontend SSE client parses). sse-starlette is
# intentionally NOT a dependency — the shared ai_shared.sse helpers are the single
# SSE-formatting source of truth (design "SSE contract"; buglists BUG-004): the
# helpers already produce fully-formatted `event:`/`data:` frames, and
# EventSourceResponse would double-encode them.
#
# The Tavily client (`tavily-python`) is pulled in transitively by the editable
# ai_shared install (its `search` extra / wrapper); the service never imports the
# SDK directly — it uses ai_shared.search.TavilySearch.
